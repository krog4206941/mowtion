What happens

        
    
          
  1. Your words. Type them, or drop a clip you already recorded.
    2. 
          
  2. A voice, if you need one. Typed scripts are spoken with a free built-in voice.
    3. 
          
  3. Pictures and music. Cards, charts, and type move with the beat. The score ducks under the voice.
    4. 
          
  4. A file you can post. Vertical or widescreen, with an optional title, description, and cover.
    5. 
        

        
Nothing is uploaded. The video is made on this computer. The first run downloads the voice and transcription models.
